**Design language — "Afterglow":** a room with the lights down and one sign on. Near-black warm ground, a single
violet-to-pink neon source (the logo), and champagne gold used only as hairlines and one solid call to action.
Didone serif for the voice, wide-tracked sans for labels, generous dark space so the glow carries the card.

Address side: the ivory half is left clear for Mailbox Power's address and postage, and the USPS barcode zone
(bottom 5/8", right 4 3/4") is untouched. The QR code goes to https://zencontentlab.com.
